# Alfred Station — ARMv7 stable release contract

This public repository distributes **only compiled artifacts and their integrity metadata**. Private source, secrets, voice and device configuration remain in `Dmitry-dev-pet/alfred-station`.

A **stable** published Release is a full (non-prerelease, non-draft) GitHub Release with:
- An immutable version tag of the form `vX.Y.Z`, exactly three numeric components. No renaming/replacing a published tag or artifact.
- **Exactly one executable asset**, named `station-armv7`, containing the Linux ARM32/ARMv7 EABI5 static ELF built from pinned private source with Go1.27.4 and tested in host + QEMU.
- **Exactly one tiny text asset**, named `station-armv7.manifest`, **generated by the owner-gated publisher** from the exact verified ELF bytes and approved tag, never supplied by an arbitrary issue or URL.
- Exact SHA-256 and byte count of **both** assets independently checked against the GitHub API before the draft Release is published, plus provenance of the private source commit/PR and sanitized test receipt.

The text manifest is UTF-8/ASCII, four LF-terminated lines, no extra fields:
```text
ALFRED_STATION_STABLE_V1
tag=v2026.11.17
size=6357116
sha256=<64 lowercase hexadecimal characters>
```
The above SHA placeholder is **not a deployable manifest**. Actual manifest digest and content must come from the exact pinned ELF.

On-device `station-release-updater.sh` reads **only** `/releases/latest/download/station-armv7.manifest`, then downloads `station-armv7` from that immutable tag and verifies its size, digest and ELF architecture. The previous *installed* ELF's SHA-256 must match a separately published immutable old Release **before** updating. The old binary is not kept on disk; recovery re-downloads it from its pinned GitHub tag. Offline rollback is **not** guaranteed. A sleeping Station is not considered broken just because MCP has been quiet.

Experimental/preview Releases may remain GitHub prereleases, but they are never selected by `/releases/latest` and are **not** eligible for unattended installation.

**Publisher authority:** only the narrowly scoped, owner-controlled operator-only route in [github-control PR #285](https://github.com/Dmitry-dev-pet/github-control/pull/285), after security review and explicit GitHub App installation to this single repository. It never builds on Actions, accepts arbitrary URLs/paths, reads the Station key, or modifies the device. Draft code is not permission to publish.

**Current state:** no published releases; no Mini 2 self-update performed. Actual live installed hash, hardware HTTPS/CA, `/tmp` tmpfs, UBIFS/flash reserves and voice regression require the separate read-only [Station #57](https://github.com/Dmitry-dev-pet/alfred-station/issues/57) / [TruthRail #414](https://github.com/Dmitry-dev-pet/truthrail/issues/414) gates. Keep automatic updates off until all hardware and publisher gates pass.

Never publish a binary from an unreviewed staging commit or use the outdated 2026-11-17 staging SHA `e4969cf9...` as the corrected PR60 candidate. See private [alfred-station PR #60](https://github.com/Dmitry-dev-pet/alfred-station/pull/60).
